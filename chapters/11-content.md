# 11 · 路线 G：内容、课程与招聘机会

> 核心判断：技术文档与公开作品可以带来教育服务和工作机会，但不是平台自动分钱。

## 逐步执行

1. 1. 选一个能长期输出的专业主题
2. 2. 用 GitHub 汇总可复现的教程、工具和结果
3. 3. 发布跨平台原创拆解
4. 4. 给目标人群明确下一步
5. 5. 归因来源。

## 本章验收

3篇原创拆解 + 1份公开作品集。

## 对抗式检查

**常见误区：** 假装客户背书；用薪资承诺诱导。

问自己：我有哪条证据证明这一步可以推进下一步？没有证据，就记录为待验证假设。
