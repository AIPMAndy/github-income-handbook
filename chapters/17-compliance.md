# 17 · 版权、税务与平台红线

> 核心判断：合法经营、尊重许可、保护隐私是赚钱的前提。

## 逐步执行

1. 1. 为代码设置合适许可证
2. 2. 标明第三方来源和授权
3. 3. 不提交 token、客户数据、合同
4. 4. 检查 GitHub Pages/赞助政策
5. 5. 按收入所在地和经营形态核对税务义务
6. 6. 勿伪造收款身份。

## 本章验收

开源发布前审计单及免责声明。

## 对抗式检查

**常见误区：** 违反许可二次售卖；买卖账号；声称规避审查；承诺免税。

问自己：我有哪条证据证明这一步可以推进下一步？没有证据，就记录为待验证假设。
