# 04 · 用 README 把流量变成信任

> 核心判断：README 要回答“这东西能替我节省什么”。

## 逐步执行

1. 1. 首屏一句人话解释价值
2. 2. 使用前后效果对比，严禁伪造
3. 3. 3分钟上手步骤
4. 4. 放真实截图或 GIF
5. 5. 给出常见失败解法与反馈路径。

## 本章验收

一份包含真实演示、开始步骤、限制说明的 README。

## 对抗式检查

**常见误区：** 一屏全是徽章、空洞奖项和自夸。

问自己：我有哪条证据证明这一步可以推进下一步？没有证据，就记录为待验证假设。

## 可复制工作表

- 目标用户：
- 要解决的问题：
- 当前替代方案：
- 最小交付物：
- 验收证据：
- 时间 / 现金成本：
- 最大风险：
- 下一次复盘日期：
