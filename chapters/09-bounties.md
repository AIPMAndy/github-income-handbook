# 09 · 路线 E：任务悬赏与开源贡献

> 核心判断：只有明确资助方、任务条款与验收标准的悬赏才值得投入。

## 逐步执行

1. 1. 从项目官方 Issue 或认可的悬赏页找到任务
2. 2. 阅读资格、冲突、期限和付款条件
3. 3. 先沟通再编码
4. 4. PR 留证据
5. 5. 按约定核验结算。

## 本章验收

可追溯的悬赏工单（任务链接、付款主体、接受标准）。

## 对抗式检查

**常见误区：** 无资金证明就投入大工时；破解系统或绕过平台审核；保证回款。

问自己：我有哪条证据证明这一步可以推进下一步？没有证据，就记录为待验证假设。

## 可复制工作表

- 目标用户：
- 要解决的问题：
- 当前替代方案：
- 最小交付物：
- 验收证据：
- 时间 / 现金成本：
- 最大风险：
- 下一次复盘日期：
