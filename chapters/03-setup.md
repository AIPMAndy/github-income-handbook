# 03 · 新手建库：15分钟把门面搭好

> 核心判断：仓库是项目说明书，也是你的可信度证明。

## 逐步执行

1. 1. 注册 GitHub 并开启2FA
2. 2. New repository，设公开并添加 README
3. 3. 写明项目服务谁、能解决什么、如何体验
4. 4. 补 LICENSE、截图、使用边界、联系方式。

## 本章验收

一个可访问、可复现的最小公开仓库。

## 对抗式检查

**常见误区：** 只有标题没有演示；没有授权协议；公开 API Key。

问自己：我有哪条证据证明这一步可以推进下一步？没有证据，就记录为待验证假设。

## 可复制工作表

- 目标用户：
- 要解决的问题：
- 当前替代方案：
- 最小交付物：
- 验收证据：
- 时间 / 现金成本：
- 最大风险：
- 下一次复盘日期：
