# 00 · 从这里开始

> 核心判断：别急着建仓库，先找到一个愿意付费的问题。

## 逐步执行

1. 1. 列出你曾帮别人解决的3个问题
2. 2. 找5位潜在用户核对频率和损失
3. 3. 从中选出可在7天内交付的一个
4. 4. 写一张问题卡。

## 本章验收

一张有具体目标用户、现有替代方案、待验证假设的问题卡。

## 对抗式检查

**常见误区：** 把兴趣误当需求；看到热门项目就直接复刻。

问自己：我有哪条证据证明这一步可以推进下一步？没有证据，就记录为待验证假设。

- 当前替代方案：
- 最小交付物：
- 验收证据：
- 时间 / 现金成本：
- 最大风险：
- 下一次复盘日期：
