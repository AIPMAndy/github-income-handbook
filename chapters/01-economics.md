# 01 · GitHub 如何形成收入

> 核心判断：Star 是关注信号，收入要经过交易链路。

## 逐步执行

1. 1. 区分开源项目、分发渠道、商业交付
2. 2. 用“访问→有效线索→订单→交付→复购”建漏斗
3. 3. 为每个环节写可观察指标
4. 4. 设定成本与证据门槛。

## 本章验收

漏斗指标表与第一笔交易的验收标准。

## 对抗式检查

**常见误区：** 把 Star、Fork、搜索排名直接当成销售额。

问自己：我有哪条证据证明这一步可以推进下一步？没有证据，就记录为待验证假设。

## 可复制工作表

- 目标用户：
- 要解决的问题：
- 当前替代方案：
- 最小交付物：
- 验收证据：
- 时间 / 现金成本：
- 最大风险：
- 下一次复盘日期：
