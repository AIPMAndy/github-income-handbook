# 19 · 常见问题与谣言鉴别

> 核心判断：收入不会因为使用 GitHub 自动出现。

## 逐步执行

1. 1. 没有写代码能力，也可用文档或可复用方法验证需求
2. 2. 开源与商业服务可以共存，但要尊重许可
3. 3. GitHub Sponsors 因地区与资质而异
4. 4. 仓库可以提供信誉，不等于交易平台
5. 5. 任何保证月入的说法都需要证据。

## 本章验收

完成反常识检查表，至少否决一个错误路径。

## 对抗式检查

**常见误区：** 相信“复制一个仓库就自动躺赚”。

问自己：我有哪条证据证明这一步可以推进下一步？没有证据，就记录为待验证假设。
