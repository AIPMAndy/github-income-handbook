# 开源商业化与平台合规边界

## GitHub Pages

GitHub Pages 适合静态开源作品和教程展示，但官方明确限制把它作为商业交易站或收费 SaaS 免费托管。本站不提供站内付款、订阅、交易和私人资料提交。商业服务由作者独立官网承载，请自行确认外链页面合规。

## GitHub Sponsors

收款地域资格与税务合规请始终以官方条款为准。不得借用虚假身份绕过地区资格，也不要把 Sponsorship 包装成“零门槛赚钱”。

## 版权许可

代码许可（本库 MIT）与内容许可（本库 CC BY 4.0）不同；第三方素材、品牌 Logo、演示数据须另行确认授权。商业定制涉及客户知识产权归属，必须书面约定。

## 数据与安全

不得在仓库或 Issue 发布密码、Token、客户数据、银行信息、医疗信息、受保密协议约束的内容。及时撤销已泄漏密钥，仅删除提交历史不等于密钥不再有效。

## 收入与税务

合法经营、按所在地法律确定开票与纳税义务。个体户或公司登记取决于业务连续性、组织形态、交易对象、所在地政策等，不能用单一收款金额当成全国统一免审查门槛。本站不提供个案税务/法律意见。
