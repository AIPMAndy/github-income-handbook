# 30 天执行清单（不承诺成交）

## 第 1 周：找到真实问题

- [ ] 列出 10 个我能解决的问题
- [ ] 与 5 位真实潜在用户交流（得到明确同意，不采集敏感信息）
- [ ] 记录现有替代方案、频率和损失
- [ ] 选择一个 7 天可完成的最小交付
- [ ] 写清楚该问题为什么值得付费

## 第 2 周：做成公开资产

- [ ] 完成可运行或可复现的 Demo / 模板
- [ ] 创建公开仓库与 README
- [ ] 设置适当 LICENSE 与第三方授权说明
- [ ] 录制/制作真实演示
- [ ] 让至少 1 名非作者用户完整走通

## 第 3 周：找对人

- [ ] 产出 3 篇原创问题拆解
- [ ] 回答 5 个相关社区中的真实问题，尊重社区规则
- [ ] 对站内自然反馈分类
- [ ] 为具体客户问题拟定交付方案
- [ ] 记录有效询盘与来源

## 第 4 周：试单与复盘

- [ ] 有意向则做一次清晰报价
- [ ] 真实交付、验收、记录变更
- [ ] 记录成交或拒绝原因
- [ ] 核算净收入、人工时间和额外成本
- [ ] 决定继续、转向或停止

每一天都问：今天新增的证据是什么？
